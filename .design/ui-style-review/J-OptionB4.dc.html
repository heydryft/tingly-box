层次怎么来的
  • 底：极淡的蓝紫光晕渐变，不是大块灰
  • 卡片：白色，1px 淡边加两层柔阴影
  • 卡内：标题带（CONNECTION）和展开区各自一个更浅的渐变底
  • 三层之间靠明度和阴影区分，不靠粗边框
美感细节
  • Agent 与厂商用圆角彩色图标块，路由用虚线加图标表达，不再是方盒子
  • 状态、上下文、端点统一为柔色胶囊；Healthy 绿、No key 琥珀
  • 主按钮微渐变加内高光和蓝色柔影，全页只此一个实心强调
  • 数值放进浅底输入框样式的字段里，复制图标在末端
代价与取舍
  • 比现在更"精致"，但要新增图标块、胶囊、渐变等令牌，工作量大于 B2
  • 阴影和渐变在暗色主题要重新设计（用描边加微亮度代替阴影）
  • 规则卡左侧状态边需要真实的健康数据支撑
