还乱在哪：五个主题
1. 同样的按钮，不同的行为
Agent 头部 Requests / Usage / Log 长得一样，一个开弹窗、一个跳走、一个开另一种弹窗（A12、X1）。
2. 提示与修复分开放
"Config out of date" 在左边是一行字，修它的按钮在最右（A13）；新手还没配就先看到"过期"（A19）。
3. 没数据时也下结论
零流量时缓存命中率红色告警、错误率绿色健康（D7）；空状态不给下一步（D18）。
4. 一个控件三种长相
Dashboard 三个子页三种时间段控件和三套选项（D15）；三个"请求列表"三套列（X1）。
5. 名字没对齐
Agent / 智能应用 / Scenario / claude_code；Quick Start / Setup Guide；Plugins 指两样东西；中文漏翻（X2、X3）。
